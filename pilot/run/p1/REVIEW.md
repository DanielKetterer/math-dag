The checker found three cycles and 17 places where Common Core grade order
puts a node before its prerequisite. Curricula can refute an edge but never
confirm one, so each of these points at a wrong edge or a node that is too big.

**One pattern explains most of the grade-order findings: a number-range merge
across a real threshold.** A node merged from two grades (expanded form for
2.NBT.A.3 and 4.NBT.A.2; the standard algorithm for 3.NBT.A.2 and 4.NBT.B.4;
multistep problems for 3.OA.D.8 and 4.OA.A.3; and two merges Claude made,
addition.base-ten.like-units and .compose-unit, which absorbed the 1.NBT.C.4
nodes) is placed at the earlier grade but carries the later grade's
prerequisites (place-value.ten-times-right, hundreds, partial quotients).
Proposed rule for RULES 2.4: **a number range changes the mathematics exactly
when it changes the prerequisite set**, so such a merge is two nodes. If you
agree, the fix is a split of each node listed in 97, by script plus a small
proposer run in the next slice.

95. **Cycle:** comparing.whole-numbers.symbols needs equation.equal-sign.meaning,
    and equation.equal-sign.meaning (route via-symbols) needs
    comparing.whole-numbers.symbols. Both whys say the same thing: '=' means same
    value. Proposed: drop the via-symbols route; the equal sign's meaning has its
    other route, and the symbols node uses '='.
96. **Cycle:** subtraction.unknown-addend.meaning (route distance) needs
    subtraction.comparison.number-line, a grade 2 number-line node whose own
    edge (re-pointed from the retired subtraction.whole-number) now needs
    subtraction.base-ten.strategy, which needs within-20 fluency, which (route
    related-addition) needs the unknown-addend strategy. Proposed: drop the
    distance route on subtraction.unknown-addend.meaning (a number-line
    representation cannot ground the first meaning of a difference), and point
    subtraction.comparison.number-line at subtraction.within-20.fluency instead
    of the base-ten strategy.
97. **Range merges to split** (yes / no per node): place-value.expanded-form
    (2 vs 4), addition.standard-algorithm and subtraction.standard-algorithm
    (3 vs 4), operations.application.multistep (3 vs 4),
    addition.base-ten.like-units and addition.base-ten.compose-unit (1 vs 2),
    comparing.whole-numbers.magnitude, numeral.write.to-1000,
    place-value.ten-more-less (1 vs 2: tens only versus hundreds).
98. **Parentheses:** multiplication.associative, .distributive and
    addition/subtraction.base-ten.explain need expressions.grouping.evaluate, a
    grade 5 node (nested grouping, order of evaluation). The grade 3 properties
    use one pair of parentheses as 'do this first'. Proposed: a small new node
    expressions.parentheses.do-first that these point at; the grade 5 node then
    needs it.
99. **Standard algorithm and ten-times-right:** the addition and subtraction
    algorithms and multiplication.by-multiple-of-ten need
    place-value.ten-times-right (4.NBT.A.1, the general 10x relation between
    adjacent places). Regrouping needs only that ten of a unit make one of the
    next (addition.base-ten.compose-unit / subtraction.base-ten.decompose-unit).
    Proposed: replace with those.
100. **operations.application.multistep** needs partial products and partial
    quotients (critic's missing prerequisite). At 3.OA.D.8 (within 100) the facts
    suffice; this is the range problem of 97 again.
