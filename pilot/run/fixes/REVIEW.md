   - Proposer's why: The learner must already judge which of two very unequal sets has more before the meaning of 'more' can be tied to number rather than size.
   - Critic: Perceptual comparison covers sets so unequal that number and size agree. The test pits number against size and spread, so a perceptual judgment is exactly what the node must override and cannot supply the meaning. It is a developmental precursor for the word 'more', not a requirement.
